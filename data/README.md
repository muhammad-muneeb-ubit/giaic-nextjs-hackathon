# Data Storage Directory

This directory is organized for storing text format data in the following structure:

## Directory Structure

- **`text-files/`** - General text files and plain text documents
- **`notes/`** - Notes, memos, and quick text entries
- **`documents/`** - Formatted documents and longer text content

## Usage

1. Place your text files in the appropriate subdirectory based on content type
2. Use descriptive filenames for easy identification
3. Supported formats: `.txt`, `.md`, `.json`, `.csv`, and other text-based formats

## File Naming Convention

- Use lowercase letters and hyphens for file names
- Include dates when relevant: `YYYY-MM-DD-filename.txt`
- Be descriptive: `meeting-notes-2024-01-15.md`

## Examples

```
data/
├── text-files/
│   ├── sample-data.txt
│   └── configuration.json
├── notes/
│   ├── daily-notes-2024-01-15.md
│   └── project-ideas.txt
└── documents/
    ├── project-documentation.md
    └── requirements.txt
```
